## 何を間違えたか（事実 → 判断のズレ）

1. **「割引」と書いた馬を無印にした（実質の消し）**: 1 ギャラボーグは阪神JF 2着・桜花賞 2着と、GI 連対が2回ある。
   「2000m未経験・春以来半年ぶり（休み明け＝割引）」として総合 +1 を付けながら、選定は「-」にした。
   全頭表の総合では相手に入れた 6・14 と同じ +1 だった。免責チェック（ゲート3）は「休み明け」の語があるので通ったが、
   中身は消しと変わらない。前走 GI 連対馬の直行ローテを休み明けで割り引いたことも誤り。
   ユーザーに「穴馬も考慮したか」と聞かれた時点で、外した馬として 1 の名前を挙げていたが、買い目は変えなかった。
2. **◎ 1.3 倍で BOX を組んだ**: 5頭BOX は10点中6点が ◎ を含まない。◎ が連対すれば（想定7割超）その6点はすべて外れる。
   実際、◎ が1着に来ても、2着が BOX 外だった時点で全滅した。◎ から相手10頭への馬連流しなら 1-8 の 1,600円で、回収率は 160% だった。
   BOX はユーザーの指定だったが、◎ 軸流しとの差を示さずに組んだ。
3. **買い目表を採点器が読めない形式で書いた**: `| # | 組み合わせ | 金額 |` の表は output-schema §4（`| 買い目 | 推定オッズ | 投資額 | 想定払戻 |`）と違う。
   score_prediction.py は「投資 0 円」と採点し、validate_output.py もこれを検出しなかった。
   時間不足の中、過去ファイルの見出しだけを見て書いたのが原因。
